# Blocks List

Registry of reusable blocks/components so new sections can reuse existing HTML + CSS instead of rebuilding it. Includes both true Shopify blocks (repeatable block types within a section schema) and shared component classes from `css/components.css`.

| Block / component | Used in | Location | Notes |
|---|---|---|---|
| Pill button (`.btn--pill`) | `hero_banner` | css/components.css | Pill shape/sizing only — no color; compose with a skin class. |
| Icon-circle button (`.btn--icon-circle`) | `hero_banner` | css/components.css | Circular shape/sizing only — no color; compose with a skin class. |
| Primary button skin (`.btn--primary`) | `hero_banner` | css/components.css | Cream fill + navy-ink border/label (`--color-cream`, `--color-btn-ink`, `--border-width-btn`). Stacks with `.btn--pill` or `.btn--icon-circle` for shape, e.g. `class="btn btn--pill btn--primary"`. |
| Button group (`.btn-group`) | `hero_banner`, `product_carousel` | css/components.css | Flex row that pairs a pill CTA with a secondary icon button, wraps on small screens. Reused in `product_carousel`'s `nav_style = "cta"` variant with the `.btn--outline` skin (e.g. "Build Your Bundle" + diagonal-arrow icon-circle) in place of the default prev/next arrows. |
| Marquee item (`marquee_item` block, `.marquee__item` + `.marquee__icon`) | `promo_marquee` | css/sections/marquee.css | Repeatable ticker text block; sparkle SVG divider renders after each item. Track is duplicated 6x in HTML (1 real + 5 aria-hidden) and animated -16.6667% (1/6) via `@keyframes marquee-scroll` — 2 copies isn't enough for this short item set to reach the edge of a wide viewport, which left a visible blank gap right before the loop restart; same fix as `announcement_bar`. Predates the shared `.ticker` component below — kept on its own classes/keyframes rather than migrated. |
| Ticker (`.ticker`, `.ticker__track`/`__group`/`__icon`) | `announcement_bar` | css/components.css | Shared infinite-scroll mechanics (flex track, `@keyframes ticker-scroll`, reduced-motion off-switch) factored out for reuse — wrap with a section class for background/border and an item class for text skin instead of re-declaring the scroll animation. `promo_marquee` predates this and still uses its own `.marquee__track` (see row above); point any *new* ticker-style section at `.ticker` instead. |
| Announcement item (`announcement_item` block, `.announcement-bar__item` + `.ticker__icon`) | `announcement_bar` | css/sections/announcement-bar.css | Repeatable ticker text block on the shared `.ticker` mechanics; pink bg + rust-red text (no border), vs. `promo_marquee`'s red bg + white text + blue rule. Text uses its own dense-UI type spec rather than the site's Comic Neue display voice: `--font-ui` ("Inter", 700), `--fs-ticker-item` (12px), `--lh-relaxed` (120%), `--ls-snug` (-0.12px), `--color-rust` (#9a1902) — distinct token set from `promo_marquee`'s `.marquee__item`. |
| Stroked heading (`.stroke-heading`, `.stroke-heading--white`, `.stroke-heading--black`) | `hero_banner`, `world_grid`, `product_carousel` | css/components.css | Display-font headline. Default: red fill + white stroke + drop shadow. `--white`: white fill + coral stroke + shadow (saturated backgrounds). `--black`: black fill + thick white stroke, no shadow — flatter look, used by `product_carousel`'s "Combo" instance (`.product-carousel__heading--display` sets its size/line-height). Compose with a section class that sets font-size/line-height. |
| World card (`world_card` block, `.world-card` + `.world-card__media`) | `world_grid` | css/sections/world-grid.css | Repeatable rounded card block: full-bleed photo background (`object-fit: cover`, clipped by the card's `overflow: hidden`) with heading top-left + supporting text bottom-left overlaid on the photo's plain-color side. `--orange`/`--cream` modifiers set the fallback background color shown before the photo loads. |
| Red button skin (`.btn--red`) | `product_carousel` | css/components.css | Solid `--color-brand-red` fill, white label, 2px white border, skeuomorphic `--shadow-btn-pop` bottom edge. Own type spec (Fredoka 600/17px) overriding the base `.btn` (Comic Neue) — this skin's only use case. Darkens to `--color-brand-red-dark` on hover. Stacks with `.btn--pill`/`.btn--block`. |
| Outline button skin (`.btn--outline`) | `product_carousel` | css/components.css | Transparent fill, thin navy-ink border, no shadow. Used for the carousel prev/next `.btn--icon-circle` controls. |
| Block modifier (`.btn--block`) | `product_carousel` | css/components.css | Stretches any `.btn` to 100% width — used for the full-width Add to Cart CTA. |
| Badge (`.badge`, `.badge--green`, `.badge--orange`) | `product_carousel` | css/components.css | Small uppercase pill label, Inter 500. Green skin doubles as both the corner "bought/social-proof" tag and the inline "Save ₹x" tag; orange skin is the "Best Seller" corner tag — both skins share the same dark-ink text color regardless of pill color. |
| Star rating (`.rating`, `.rating__stars`, `.rating__count`) | `product_carousel` | css/components.css | Row of filled star SVGs (`--color-star`) + Inter review-count text. Rating value is currently static markup (5 filled stars); wire to `rating_value`/`rating_count` block settings in Liquid. |
| Price (`.price`, `.price__sale`, `.price__compare`) | `product_carousel` | css/components.css | Inter medium sale price + muted strikethrough compare-at price (same size, both 16px), pairs with a `.badge--green` "Save" pill. |
| Variant select (`.select`, `.select__input`, `.select__icon`) | `product_carousel` | css/components.css | Pill-shaped native `<select>` (Fredoka 500, custom chevron icon overlaid, `appearance: none`) for the variant/price picker. |
| Product card (`product_card` block, `.product-card` + `.product-card__media`/`__badge`/`__title`) | `product_carousel` | css/components.css | Reusable commerce card composing badge + media, rating, title (Fredoka 500/22px), price, select, and a `.btn--red.btn--block` CTA. Reuse for any future product-grid section instead of rebuilding. |
| Large rating modifier (`.rating--lg`) | `testimonial_carousel` | css/components.css | Bumps `.rating__stars` icon size up (14px → 18px) with no count shown — used for review cards where the count doesn't apply. |
| Testimonial card (`testimonial` block, `.testimonial-card` + `__media`/`__body`/`__title`/`__text`/`__divider`/`__author`) | `testimonial_carousel` | css/components.css | Reusable review/UGC card: bordered rounded card, top photo (`aspect-ratio: 4/5`, `object-fit: cover`), then `.rating--lg`, bold title, muted body copy, a divider rule, and author name. Reuse for any future reviews/UGC section instead of rebuilding. |
| Outline button skin (`.btn--outline`) reuse | `chaos_banner` | css/components.css | `.btn--pill btn--outline` + `.btn--icon-circle btn--outline` pair reused for the "Shop Now" CTA, same pattern as `product_carousel`'s `nav_style = "cta"` variant. |
| Newsletter form (`.newsletter-form`, `__input`, `__submit`) | `footer` | css/components.css | Email-capture card: cream (`--color-card-bg`) fill + navy border wrapping a translucent pill `<input>` and a dedicated `.newsletter-form__submit` pill button (Inter 700, `--color-brand-red-bright` fill) — kept separate from `.btn--red`, which is now specialized (Fredoka/bordered) for Add to Cart only. Reuse for any future signup/newsletter section instead of rebuilding. |
| Footer column (`footer_column` block, `.footer__column` + `.footer__column-heading`/`.footer__links`) | `footer` | css/sections/footer.css | Repeatable link group: muted-red (60% opacity) Inter 600 column heading + stacked list of bright-red (`--color-brand-red-bright`) Inter 700 uppercase links. 5 instances on the homepage footer (Drinks, Makhanas, Explore, Munchief, Legal). |
| Blob photo callout (`.footer__bubble`) | `footer` | css/sections/footer.css | Irregular blob-shaped (organic `border-radius`, 240:185 aspect) photo frame with a thick white border, rotated (-15.88deg/+5.14deg) and absolutely positioned to bleed off the footer's oversized heading — stands in for the design's pre-composited footer-cloud-left/right.png cutouts. Hidden below the tablet breakpoint rather than shrunk, to avoid crowding the heading on narrow phones. |
| Nav dropdown (`nav_link` block, `.site-header__nav-item`/`__nav-link`/`__dropdown`/`__dropdown-link`) | `header` | css/sections/header.css | Repeatable left-nav item: uppercase Fredoka 500 `<button>` (label + filled chevron-down icon that rotates 180° when open) revealing a bordered `.site-header__dropdown` panel of links. Opens on `:hover`/`:focus-within` (CSS only) or via a click-toggled `.is-open` class (small script in index.html / sections/header.html — closes other open menus, outside clicks, and Escape). 2 instances on the homepage header (Products → 3 links, Learn → 2 links). |
| Header action pill (`.site-header__action`, `--bundle` modifier, `.site-header__ribbon`, `.site-header__cart-count`) | `header` | css/sections/header.css | Outline pill button (Fredoka 600, icon + label) for Account/Cart; `--bundle` modifier swaps in a bright-yellow fill + flat black pop shadow + a floating gradient "Bestseller" ribbon (Poppins 500) for the CTA. Cart variant adds an absolutely-positioned count bubble, hidden via opacity at 0 items. Mobile: `header` collapses the left nav (`.site-header__nav`) below 720px rather than adding a hamburger/drawer — revisit if the real nav grows beyond 2 links. |
| Outline button skin (`.btn--outline`) reuse | `brand_story` | css/components.css | Single `.btn--pill.btn--outline` with a trailing inline diagonal-arrow SVG (not a separate icon-circle) for the "About Munchiefam" CTA — relies on `.btn`'s existing flex `gap` rather than a new combined-button class. |
| Framed rotated photo (`.brand-story__photo`, `.brand-story__characters`) | `brand_story` | css/sections/brand-story.css | Thick white-bordered, drop-shadowed, slightly rotated photo frame — same "white border + shadow + rotate" idea as footer's blob callouts, but plain rounded-rect instead of an organic blob shape. Reuse for any future rotated-photo callout instead of rebuilding. |
| Wavy section rule (`.brand-story::before`/`::after`) | `brand_story` | css/sections/brand-story.css | Hand-drawn sine-wave SVG data-URI, repeat-x, straddling the section's top/bottom edges — same "decorative edge" pattern as footer's scalloped `::before` (css/sections/footer.css) but a wave instead of circles. Point any future wavy-border section at this instead of re-deriving the SVG path. |
